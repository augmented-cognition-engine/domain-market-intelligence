# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
By participating in project spaces, you agree to abide by its terms.

Report conduct concerns to **conduct@querylabs.ai**. Reports will be handled privately and fairly.
This policy applies to repository interactions and to anyone representing the project in public
spaces.
