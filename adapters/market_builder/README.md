# ACE Market Intelligence Builder

This separately installed trusted application adapter proposes and executes the bounded recorded
Market Intelligence v1 proof. It binds the exact reviewed GPT-5.6 Terra price publications to the
inert Market Domain Pack through Core-owned planning, authority, admission, derivation, first-Brief,
and resource-plane ports.

The planner is proposal-only. The executor receives only invocation-scoped Core capabilities after
the user has reviewed the exact sources and approved the exact build. It adds no connector catalog,
network client, credential store, delivery authority, or second intelligence runtime.
